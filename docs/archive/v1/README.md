# v1 문서 보관소

**이 디렉터리의 문서는 더 이상 유효하지 않다.** 다른 제품을 설명한다.

v1 HowSheet는 사용자가 단계를 하나하나 입력해 분기 있는 절차 문서를 만들고, 그것을
독립 실행형 HTML 리더로 내보내는 **저작 도구**였다. M1~M8까지 구현했다.

v2 HowSheet는 자료를 붙여넣으면 **한 페이지 HTML을 만드는 프롬프트**를 써 주는
생성기다. 결과물이 HTML 파일에서 프롬프트 텍스트로 바뀌었고, 그에 딸린 개념
대부분(분기 절차, 리더 런타임, 진행 저장, 가이드 문서 스키마)이 함께 사라졌다.

현재 유효한 문서는 `docs/HowSheet_v2_제품정의.md`와 `docs/HowSheet_v2_Harness_KR.md`다.

## 왜 지우지 않고 남기는가

- v1의 결정 근거가 v2에도 그대로 적용되는 대목이 있다. 특히 살균 경계(기술 §7.1),
  디자인 토큰과 타이포 계약(디자인 §4), 접근성·인쇄 기준이 그렇다.
- `artifacts/qa/phase-reports/M1~M8.md`가 이 문서들의 절 번호를 참조한다. 참조가
  끊기면 그 보고서를 읽을 수 없다.
- v1에서 살아남은 코드(`features/sanitize/`, `styles/`, `components/ui/`,
  `storage/`)의 주석이 이 문서들을 인용한다.

## 읽을 때 주의

절 번호로 인용된 근거를 확인할 때만 쓴다. **여기 적힌 요구사항을 새로 구현하지
않는다.** v1의 불변식 15종도 v2의 불변식 10종으로 교체됐다 - 번호가 겹치지만
내용이 전혀 다르므로, v2 코드에서 "INV-04"를 보면 v2 제품정의 §8을 본다.
