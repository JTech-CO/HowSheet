## 설계 판단

### 저장소는 IndexedDB, Dexie는 쓰지 않는다

담는 것이 문서 하나뿐이라 LocalStorage로도 될 것 같지만 두 가지가 걸린다.
붙여넣는 자료가 수백 KB일 수 있어 5MB 상한에 가까워지고, LocalStorage 쓰기는
**동기**라 자동 저장이 돌 때마다 그 크기만큼 메인 스레드가 멈춘다. 300KB 왕복을
테스트로 고정했다.

Dexie는 다시 들이지 않았다. 오브젝트 스토어 하나에 키 하나이고, Dexie가 주는
쿼리·마이그레이션·테이블 관계가 전부 필요 없는데 번들에는 다 들어온다. v1은
테이블 셋에 트랜잭션이 필요해 값을 했지만 v2는 아니다.

### 저장소는 던지지 않는다

열기 실패, 읽기 실패, 쓰기 실패를 전부 메모리 폴백으로 흡수한다. **저장이 안
된다고 입력까지 막으면 사용자는 작업 자체를 못 한다.** 대신 어느 모드인지
노출해 화면이 "이 탭에만 있습니다"라고 알린다.

한 번 실패하면 그 뒤로 메모리 모드를 유지한다. 매번 다시 시도하면 자동 저장이
돌 때마다 예외를 만든다.

### 저장 실패가 메모리 문서를 덮지 않는다 (INV-07)

저장은 메모리를 저장소로 밀어내는 방향이다. 실패하면 저장소가 뒤처질 뿐 편집
중인 자료는 그대로다. 저장하는 사이에 더 입력했으면 스냅샷으로 덮지 않는다 -
덮으면 그 사이의 타이핑이 사라진다.

### 원문과 미리보기를 나란히 두지 않는다

좁은 화면에서 두 칸으로 나누면 어느 쪽도 읽히지 않는다. 320px에서 한 칸씩
쓰려면 전환이 맞다. (INV-10)

### 토큰 수는 어림수이고 그렇게 말한다

정확한 값은 모델의 토크나이저만 알고, 그것을 브라우저로 가져오려면 수 MB짜리
사전이 필요하다. 이 값의 쓸모는 "이 자료가 한 요청에 들어갈 만한가"를 가늠하는
것뿐이다.

한글·한자·가나를 라틴 문자와 다르게 센다. 한 덩어리로 묶으면 한국어 문서의
토큰 수를 크게 낮잡는다. 화면에는 **"약"**을 반드시 붙이고, 테스트는 특정
숫자를 고정하지 않는다 - 지킬 수 없는 약속이기 때문이다. 단조성과 크기 감각만
단언한다.

### 상한을 넘어도 자르지 않는다

20만 자를 넘으면 경고만 하고 그대로 둔다. **자르는 것은 사용자가 모르게 자료를
잃는 일이다.** (하네스 P1 주의)

## 이번 phase에서 드러난 것

- **음성 검증이 테스트 공백을 정확히 짚었다.** 11건 중 1건이 물지 않았고, 그것이
  곧 "열기 실패 경로에 테스트가 없다"였다. 커버리지 숫자로는 보이지 않았을
  종류의 공백이다.
- **저장소 모양 검사가 필요했다.** IndexedDB에 남은 옛 형식이나 다른 데이터를
  우리 문서인 척 화면에 올리면 안 된다. `isStudioDocument`로 걸러 없는 것으로
  다룬다. 이 검사를 지우는 변이가 실제로 물었다.
- **`javascript:` 링크는 사라지지 않고 텍스트로 남는다.** 실제 브라우저에서
  확인했다. 링크로 만들지는 않지만 사용자가 무엇을 붙여넣었는지는 보인다.
- **Vite 의존성 캐시가 P0의 의존성 제거 뒤 낡아 있었다.** 콘솔에 504
  (Outdated Optimize Dep)가 남았다. 제품 결함이 아니라 개발 서버 캐시라
  `node_modules/.vite`를 지우니 사라졌다. 네트워크 요청은 전부 200이다.

## 남은 경고

- **`features/assets/data-url.ts`에 여전히 소비자가 없다.** P0 보고서에 적은
  대로 P2까지 소비자가 생기지 않으면 지운다.
- **자동 저장 간격이 v1 값 그대로다.** 500ms 목표 / 1초 하드 상한. v1은 작은
  문서 조각을 저장했고 v2는 수백 KB를 저장한다. 간격을 늘릴지는 실제 사용에서
  느려지는지 보고 정한다. 지금은 300KB 저장이 테스트에서 즉시 끝난다.
- **`useAutosave` 훅을 다시 만들지 않았다.** 스토어가 예약기를 직접 들고 있다.
  훅이 필요한 소비자가 하나뿐이라 계층을 하나 줄였다. 소비자가 늘면 다시 본다.
- **커버리지 임계가 없다.** P3·P5에서 프롬프트 조립기가 생기면 그때 건다.
- **접근성은 P7에서 본다.** `aria-label`·`aria-describedby`·`aria-pressed`를
  붙여 두었지만 키보드 완주와 스크린 리더 확인은 P7의 DoD다.
